# Security Policy

## Supported versions

Only the latest released version of each Modern Libs package receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately in one of these ways:

- GitHub private vulnerability reporting: open the affected repository, go to the **Security** tab, and choose **Report a vulnerability**.
- Email [security@modernlibs.dev](mailto:security@modernlibs.dev).

Include the package name and version, a description of the impact, and steps or a minimal sample to reproduce it.

We will acknowledge the report, keep you informed while we work on a fix, and coordinate the disclosure date with you. We credit reporters in the release notes unless they ask us not to.
