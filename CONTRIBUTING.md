# Contributing to Modern Libs

Thanks for helping. This is the default guide for every Modern Libs repository. A repository's own `CONTRIBUTING.md` overrides it.

## Before you start

- Search existing issues and pull requests to avoid duplicates.
- For a bug, open an issue with a minimal reproduction.
- For a feature or a breaking change, open an issue and agree on the approach before writing code.

## Pull requests

1. Fork the repository and branch from `main`.
2. Keep each pull request to one logical change.
3. Add or update tests for every behavior change.
4. Build and run the full test suite locally. The commands are in the repository's `README.md` or `AGENTS.md`.
5. Follow the existing code style. `.editorconfig` and the analyzers enforce it, so fix all warnings.
6. Fill in the pull request template and link the related issue.

## Commit messages

Write the subject in the imperative mood, up to 72 characters ("Fix quoted field parsing"). Explain the why in the body when it is not obvious.

## Licensing

By contributing, you agree that your contribution is licensed under the repository's license.

## Conduct

Everyone taking part must follow our [Code of Conduct](CODE_OF_CONDUCT.md).
